C3Launcher — icon concepts

Four directions, each shown at the sizes Windows actually uses. The 16 and 24px rows are the ones that matter — that is the taskbar and the window title bar. Each concept is rendered on a dark and a light strip because the taskbar can be either. All four use the launcher's existing amber and cyan.

Container Cat container

The launcher's cat in a container tile. Cyan edge = the container boundary; the tile guarantees contrast on any taskbar colour.

C3 Cat c3

The C of C3 wrapping the cat, with the omega mouth doing duty as the 3. Most on-theme; also the busiest at 16px.

Shield Cat shield

Same cat in a shield — leans on the security story rather than the container one.

Pixel Cat pixel

The cc.ps1 ASCII cat as pixel blocks. Crispest at small sizes because the cells land on whole pixels.
